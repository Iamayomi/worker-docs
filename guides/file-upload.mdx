## File Upload

The Worker API supports secure file uploads with automatic virus scanning.

### Supported Formats

| Type | Formats | Max Size |
|------|---------|----------|
| Images | JPEG, PNG, GIF, WEBP | 5MB |
| Documents | PDF | 10MB |

### Upload Flow

1. Client sends file to API
2. File is validated (type, size)
3. File is scanned for viruses (ClamAV)
4. If clean, uploaded to Cloudinary
5. URL returned to client

### Frontend Example

```javascript
async function uploadFile(file, type = 'document') {
  const formData = new FormData();
  formData.append('file', file);

  const response = await fetch(`https://api.worker.com/api/v1/upload/${type}`, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`
    },
    body: formData
  });

  const result = await response.json();
  return result.data.url;
}
```

### Security Features

<Checklist>
  - File type validation (MIME type + extension)
  - File size limits
  - Virus scanning via ClamAV
  - Automatic thumbnail generation for images
  - Secure CDN delivery via Cloudinary
</Checklist>
